# Fundamentos de Redes de Computadores

Material de estudo interativo sobre fundamentos de redes, criado a partir das minhas anotações do curso **Networking Basics**, da Cisco Networking Academy.

🔗 **Acesse:** https://mpmirandasilva.github.io/fundamentos-de-redes/

## Sobre o projeto

Transformei um resumo de cerca de 150 páginas num site para estudar de forma ativa. Ele não foi pensado para ser lido do começo ao fim de uma vez.

- **20 módulos**, do bit até os utilitários de teste de rede.
- **146 tópicos em cards** que se revelam ao clicar, na ordem do conteúdo. O próximo card só abre depois do anterior.
- **174 exercícios** com correção imediata:
  - múltipla escolha para os conceitos;
  - resposta digitada para os cálculos (binário, máscaras, sub-redes, IPv6).
- **Explicação em cada resposta**, com um link para o item do material que deve ser revisado.
- **Grifos em turquesa** nos trechos mais importantes, como numa página marcada à mão.
- **Glossário de siglas** com busca, tema claro e escuro, e progresso salvo no navegador.

## Conteúdo

| Bloco | Módulos |
|---|---|
| Conceitos básicos | Comunicação em um mundo conectado, dados, desempenho, infraestrutura, comunicação entre dispositivos |
| Redes locais e acesso | Redes sem fio e móveis, rede doméstica, mídia de rede, camada de acesso (Ethernet, MAC, VLAN) |
| Modelos e endereçamento | Modelos OSI e TCP/IP, protocolo IP, IPv4 e sub-redes, IPv6 |
| Serviços de rede | DHCP, gateway, ARP, roteamento, TCP e UDP, camada de aplicação (DNS, HTTP, e-mail) |
| Prática | Utilitários de teste (ipconfig, ping, tracert, nslookup, netstat, arp) |

## Tecnologias

O site é uma única página em HTML, CSS e JavaScript puros, sem frameworks. Os ícones em pixel art e a animação da rede foram desenhados em código (SVG e Canvas).
